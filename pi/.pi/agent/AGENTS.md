## Obsidian Vault

You may read and edit `~/Documents/MyObsidianVault/` to capture ideas, project work, and items the user wants to revisit.

For **all** vault work, load the `obsidian` skill. It routes to the focused reference for Markdown, project-note metadata, Bases, or the Obsidian CLI. Follow its project-note requirements so notes remain visible in the correct Base.

For `.canvas` files, also follow the JSON Canvas guidance.

Daily notes may capture work completed today. Store durable notes and documentation in the vault's Notes area when appropriate.
